# 数据存储

AizenAssistant 的数据保存在本地：

- 通过 `bun run dev:tui` 启动时，默认数据目录为 `<worktree>/.aizen`；相对路径以 worktree 根目录为基准；
- 直接运行 `bun apps/tui/main.ts` 时必须指定 `--data-dir <目录>`；相对路径以执行命令时的当前目录为基准；
- 运行 `aizen-assistant`（通过安装脚本安装到 `~/.aizen/bin/`）时，默认数据目录为 `<可执行文件所在目录>/.aizen`，即 `~/.aizen/bin/.aizen`；
- 直接拷贝可执行文件到任意目录运行时，数据目录跟随可执行文件，位于其同目录的 `.aizen/`（便携模式）；
- 以上启动方式都可以通过 `--data-dir <目录>` 改用指定的数据目录，数据目录不能直接指定为当前工作目录。

## 目录内容

数据目录包含会话、视图、模型配置、应用偏好和认证信息。会话按工作目录分组保存在 `sessions/` 下，每个会话对应一个 JSONL 文件；文件名由本地创建时间和助记词 ID 组成，可以在应用外改名。会话文件是完整记录的事实来源，摘要索引只是可重建缓存。全局技能登记表保存在 `skills.json`，技能仓库缓存位于 `skill-sources/`。

## 备份与敏感内容

数据全部位于 `~/.aizen/bin/.aizen`（便携模式为可执行文件旁的 `.aizen/`），其余内容（可执行文件、`install.json`）均可重新安装获得，备份时复制数据目录即可。由于其中包含认证信息，分享、同步或提交前请先检查敏感内容。
