# 会话管理

会话是 Aizen 与用户交互的完整记录，以本地单文件形式保存。本文说明会话的生命周期：从创建、标识、命名，到回退、分支、恢复与整理。

## 创建与标识

每个会话在创建时获得一个**助记词 ID**：由三个单词组成，而不是难以辨认和交流的 UUID。即使没有主动命名，你也可以用助记词方便地查找、区分和引用会话。

助记词 ID 也是会话文件名的组成部分，文件名由本地创建时间和助记词 ID 组成，可以在应用外改名。文件名不参与会话身份识别，改名不影响会话内容。

## 命名

会话支持命名，命名后可更方便地引用和区分。未命名会话使用助记词 ID 作为回退与分支时的名称来源。

## 回退与分支

- **回退（rewind）**：删除所选轮次及其后的对话内容。回退只作用于对话内容，**不会**恢复所选轮次当时的模型和视图设置——回退时正在使用的模型和视图保持不变。
- **分支（fork）**：在指定轮次创建独立分支副本，副本以原会话名加"副本"后缀命名，可以在分支上继续对话而不影响原会话。

原始记录不会因为上下文压缩而被删除，回退与分支基于完整记录进行。

## 恢复

会话支持恢复：重新打开历史会话后，可以从中断位置继续对话。恢复时模型和视图设置保持当前值，异常中断后的恢复细节见[后续计划](./roadmap.md)。

## 整理

会话可以在应用外自行改名、备份和整理。会话文件按工作目录分组保存在数据目录的 `sessions/` 下，是完整记录的事实来源，摘要索引只是可重建缓存。文件组织与备份建议见[数据存储](./data-storage.md)。
