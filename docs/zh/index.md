# AizenAssistant

面向重度 Coding Agent 用户的本地 Coding Agent 应用：适合长期维护项目、频繁切换任务方式，并希望对 Agent 上下文做定制化管理的开发者。

## 文档入口

- **用户指南**——面向使用者，无需技术背景：权限系统、自举套件等功能的安装、配置与使用。
- **开发者文档**——面向实现与维护者：模块的实现规格、接口契约与边界条件。
